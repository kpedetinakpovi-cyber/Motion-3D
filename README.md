# Motion-3D Studio

Scaffold initial créé par Copilot. Cette application fournit le coeur d'une suite d'édition/animation 2D/3D (timeline, expressions, renderer) compatible conceptuellement avec After Effects / Premiere / CapCut / Alright Motion.

Fichiers générés :
- src/core/params.ts (PARAMS_100 centralisé)
- src/core/Timeline.ts (timeline + interpolation + expressions sandbox)
- generator/motion3d-2m.ts (générateur de params)
- src/ui minimal (Vite + React)

Scripts :
- npm run dev
- npm run build
- npm run generate:params

Remarque légale : le projet ne contient pas de code propriétaire d'éditeurs tiers; il réimplémente des fonctionnalités compatibles et mappings quand possible.
