## Usage in UI

### Template Browser
- Grid/list view with thumbnails
- Search bar with autocomplete
- Category filter sidebar
- Favorite star toggle
- Apply button (adds to selected track)

### Inspector
- Template parameters editable
- Duration slider
- Preview in real-time
- Save as custom preset

### CLI
- List all templates: `motion3d-cli --list-templates`
- Apply template: `motion3d-cli --template text-fade-in --output scene.json`
